## How I work

1. Read the full instructions, examples, label definitions, and rubric.
2. Separate verified facts from assumptions or unsupported claims.
3. Check whether the response answers the request and follows every constraint.
4. Review evidence quality, internal consistency, calculations, and completeness.
5. Write a concise rationale and document edge cases for quality review.
